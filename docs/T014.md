# T014 供应商主数据

依据 V2.2 第23–25、28–31、89节及第109节 B5、B9。供应商入口为 `/suppliers`，法人主体继续使用 `business_partner`。

## 数据与权限

`0011_supplier_profile` 增加公司内唯一供应商编号、同公司主体和采购负责人外键，以及供应商档案。已有客户关联供应商时保留同一个往来 UUID 和原客户档案，角色变为 BOTH。供应商停用只影响供应商档案。新建主体和供应商档案、业务审计与幂等回执共用数据库事务。

供应商编号先 NFKC 规范化、去首尾空白并大写，数据库对同公司编号做唯一约束。采购负责人新设时须为同公司有效员工，原有停用员工仍可在历史档案显示。供应商类型为 DISTRIBUTOR、HARDWARE、SOFTWARE_SERVICE 或 GENERAL。供应商付款账期是非负整数。币种保持 CNY。

供应商读写与导入使用 supplier 权限和公司／负责人范围。关联或编辑现有主体时还需现有主体编辑权限。新建供应商主体使用 supplier.create，范围限采购负责人和供应商角色。银行账号复用共享字段，默认掩码，完整查看沿用既有独立权限和 MFA。审计只记录账号变更事实。

## 导入

标准 Excel 和 UTF-8 CSV 每批最多 100 行、256 KiB，支持显式往来主体 UUID。未指定 UUID 时，按公司内主体编码、规范化税号及统一社会信用代码匹配。提供的税号与信用代码须与命中主体一致，多候选或只命中同名主体时返回人工核对错误。关联已有客户时不写入模板中的共享字段。

导入复用创建业务校验及权限。成功行和审计在一个批次事务提交，错误单独回滚该行并返回行号、字段与原因。同一幂等键与同一文件重放结果。无新增第三方依赖。

## 迁移与 Seed

新迁移依赖 `0010_partner_bank_account_width`，有供应商档案时拒绝破坏性降级。Seed 沿用五个合成供应商主体，包括两个总代、硬件、软件服务及双角色档案。测试数据使用既有合成公司和采购员工，重复运行保留完整 ID 集合。

采购业务、应付、付款、返利和正式历史迁移不在本任务范围。
