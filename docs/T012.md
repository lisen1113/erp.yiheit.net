# T012 往来单位验收

从 ERP 首页进入「往来单位」，使用合成测试账号登录。页面在 `ERP_ENV=test` 继续显示全局测试标识。页面支持列表、搜索、分页、详情、新建、编辑、停用和启用。

API 路径为 `/api/v1/business-partners`。列表默认筛选启用记录。筛选客户或供应商均包含双角色主体。所有写请求使用 `Idempotency-Key`。编辑及状态变更须传当前 `version_no`，成功后可重新读详情取得新版本。信用额度在 JSON 中以十进制字符串传输。

T010 合成资料投影到 14 个主体，其中客户身份 10 个、供应商身份 5 个。C10 和 V05 共用 `PARTY-DUAL` 的固定 UUID，主要联系资料沿用 C10 投影。重复 Seed 保留已有合成主体，清理仅接受未修改 Seed 主体。

发票税号使用 `tax_no`。写入先执行 Unicode NFKC，去首尾空白和内部普通空格，并将 ASCII 字母转大写。空值规范为 NULL。同公司非空值受部分唯一索引约束，冲突返回 409 `BUSINESS_PARTNER_TAX_NO_CONFLICT`。T012-02 已裁决，历史重复项留待迁移暂存人工映射。并发验证为一次 201、一次 409，仅创建一条主体和对应审计，两侧幂等重放均保持原结果。完整账号仅在具有 `business_partner.bank_account.view_full` 的 MFA 会话中显式读取。
