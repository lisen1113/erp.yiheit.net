# 商品主数据清洗与切换盘点

新 ERP 分类独立设计，按通用品类定义动态规格，不继承任我行的分类结构。旧分类、编码与名称只作来源、清洗映射和追溯证据。旧编号不得自动成为新 SKU。确认多个旧记录确属同一标准商品后，可在后续迁移任务建立多对一映射。

近三年记录优先高质量清洗、映射、结构化，供后续分析。更早记录以完整保留和可追溯为先。关联依据不足的旧商品作为 Legacy 只读保留，不猜测映射。原始导出文件和裁决证据依迁移制度留档。

T015 只建立分类与属性定义，T016 建立标准商品档案。库存数量和正式期初库存由后续库存迁移任务负责。切换前全面盘点各仓，现场核对 SKU 和 SN。呆滞、损坏、待报废、账有实无、实有账无分别登记。报废完成或获批准后才裁定是否纳入新 ERP。正式期初库存使用切换日签字确认的盘点数据，老 ERP 余额仅用于差异比对。盘点差异须形成有据可查的审计清单。
